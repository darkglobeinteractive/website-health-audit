Comprehensive Website Health Audit

Baseline Evaluation & Readiness Assessment

Visibility & Search Engine Health

  • Indexing Status Site is properly indexed by Google and "discourage search engine" settings are inactive
  • Sitemap Health Site utilizes a valid XML sitemap

    Sitemap Health

    Common locations for a sitemap are:

    • Non-Yoast: /sitemap.xml
    • Yoast SEO: /sitemap_index.xml
  • SSL & Security Encryption Valid SSL certificate is active and there are no "mixed content" warnings

    SSL & Security Encryption

    You can run one of the following commands in Terminal to check this:

    • openssl s_client -connect example.com:443 -servername example.com
    • curl -vI https://example.com 2>&1 | grep -E "SSL|expire|issuer"
  • Google Analytics (GA4) Is GA4 installed and active?

    Google Analytics (GA4)

    • Search page source for gtag and look for the GA4 Measurement ID (G-XXXXXXXXXX)
    • Do you have access to the GA4 Analytics Account and Property?
  • Google Tag Manage (GTM) Is GTM installed and active?
    • Does GTM contain the proper GA4 Google Tag configured properly using the GA Measurement ID?

    Google Tag Manager (GTM)

    • Search page source for Google Tag Manager and look for the GTM ID (GTM-XXXXXXX)
    • Do you have access to the GTM Tag Manager Account and Container?
    • If you have access to the container, is there a Google Tag configured with the GA4 Measurement ID?
  • Privacy & Cookie Consent Is the site utilizing a Cookie Consent management tool or platform of some sort?

    Privacy & Cookie Consent

    Identifying if a management platform (e.g., OneTrust, CookieBot) is active for GDPR/CCPA compliance.

Speed, Performance & Quality

  • PageSpeed Insights Run the site through PageSpeed Insights and save results in a PDF
  • Browser Console Audit Verify nothing is wrong via browser inspector window

    Browser Console Audit

    Checking for hidden "red text" errors (JavaScript failures, broken assets) that break site functionality or slow down the visitor's browser.

  • Mobile UX Review Verify nothing is broken or insufficient in small mobile devices

    Mobile UX Review

    Testing the site on mobile devices to identify "tap targets" that are too small, horizontal scrolling issues, or text that is difficult to read on small screens.

  • Accessibility Compliance Checking for contrast issues, alt-text gaps, and screen-reader readiness
  • Plugin Efficiency Audit
    Plugin Name Status Action Notes
  • Software Versioning:

    Software Versioning

    Ensure the site meets the minimum requirements for WP Engine, specifically PHP 8.1+.

Architecture & Technical Infrastructure

  • Page Builder Identification Does the site use a page builder?

    Page Builder Identification

    Confirming builder version (Elementor, Divi, etc.) and license status to ensure editability.

  • Third-Party Integrations Are there any APIs or services requiring separate credentials, such as CRMs or Email platforms?
    Service Notes
  • Current Hosting Assessment

    Current Hosting Assessment

    Verification of current GoDaddy resource limits and origin server health prior to migration.
